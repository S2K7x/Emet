- [ ] Ghosts: ghost chat, ghost quests

## Phase 3: roles
- [ ] Data-driven role system
- [ ] 3 roles: Cop, Teleporter, Sacrifice
- [ ] Chaotic killer power (2 powers)
- [ ] Assignment: 2 roles offered, 1 kept

## Phase 4: multiverse
- [ ] 4 zones with different rules
- [ ] Portals and meeting place

## Phase 5: polish and content
- [ ] 6 to 8 more roles
- [ ] Game settings
- [ ] Voice, matchmaking, mobile

## Criteria for moving between phases
A playtest with real players must confirm it's fun before the next phase.
