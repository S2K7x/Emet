# Roadmap — Emet

## Phase 0: decisions
- [x] Choose the engine (see `ARCHITECTURE.md`)
- [ ] Settle the open points in `DECISIONS.md`
- [ ] Name the game and set the basic visual identity

## Phase 1: base prototype (4 players, 1 map, no roles)
- [x] Room + multiplayer connection
- [x] Synced movement
- [x] Killer: kill with cooldown
- [x] Bodies, reporting, meeting, vote
- [x] Simple win condition (killer/innocent parity / all killers ejected)

## Phase 2: quests and ghosts
- [x] Shared quest bar, 8 mini-games (one per station, `data/minigames.json`)
- [x] Ghosts: ghost chat in game · ghost quests (count + weight revival)

## Phase 3: roles
- [x] Data-driven role system
- [x] Roles: 8 innocent (incl. Cop), 2 neutral
- [x] Chaotic killer power (4 powers)
- [x] Assignment: 2 roles offered, 1 kept

## Phase 4: multiverse
- [x] 4 zones with different rules (low gravity, ice, dark, sugar rush)
- [x] Portals and meeting place (2 diagonal portal pairs, seats around the Nexus table)

## Phase 5: polish and content
- [ ] 6 to 8 more roles
- [ ] Game settings
- [ ] Voice, matchmaking, mobile

## Criteria for moving between phases
A playtest with real players must confirm it's fun before the next phase.
